# pv-comm-aware-monitoring

Code, data, and SAM exports for the paper "Communication-Aware Fault Monitoring and Classification of a Solar PV System Using SAM Simulation and a Neural Network".

**Contents:** `PV_Comm_Monitor_Package_v7.zip` is the complete package. Unzip it and follow the `README.md` inside (dataset, SAM exports, evaluation scripts, receiver-side gate, classifier, Streamlit dashboard, result files, and a dependency lock file).

Version 7.0 matches the revised paper.
